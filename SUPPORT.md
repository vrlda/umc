# Support

OpenMesh is maintained in public. Please use the right channel so maintainers
and contributors can help effectively.

## Use GitHub Discussions for

- questions about the project direction
- design feedback and architecture ideas
- operator questions and deployment discussion
- onboarding and contributor help

## Use GitHub Issues for

- reproducible bugs
- clearly scoped feature requests
- documentation mistakes with a concrete fix
- task-sized follow-up work tied to a clear component or workflow

## Do not use public channels for

- security vulnerabilities
- deanonymization risks
- secrets, credentials, or private infrastructure details
- personally identifying user or operator information

Please follow `SECURITY.md` for vulnerability reporting.

## Response expectations

- This is a volunteer-led project.
- There is no guaranteed support window or SLA.
- Clear, respectful, well-scoped reports will get help faster.
