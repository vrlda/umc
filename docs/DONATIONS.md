# Donations

OpenMesh accepts voluntary donations to support infrastructure, audits,
documentation, and long-term maintenance.

## Principles

- Donations do not buy influence over governance, roadmap, or moderation.
- Donations do not unlock features, access, or support tiers.
- Project direction stays public and community-driven.

## Before publishing this page

Replace all placeholders below with real values.

Recommended minimum setup:

- one public donation page
- one transparent wallet policy
- one short explanation of what funds are used for
- one named maintainer group responsible for treasury access

## Suggested donation page structure

### What donations support

- security review and audits
- bootstrap node and test infrastructure costs
- documentation and contributor tooling
- maintenance time for the core project

| USDC | Ethereum or Base | `TO_BE_ADDED` | Be explicit about the chain |
| XMR | Monero | `TO_BE_ADDED` | Optional, if the project chooses to support it |

### Wallet and treasury policy

Recommended policy:

- use dedicated project wallets, never personal mixed-use wallets
- prefer multisig for shared project funds
- publish which maintainers control treasury access
- document how key rotation works
- publish periodic summaries of incoming donations and major spending

### Safety note

Never reuse addresses from test environments, personal accounts, or exchange
deposit wallets.
